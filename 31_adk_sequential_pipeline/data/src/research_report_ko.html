요약

국내 IT 기업 42곳을 대상으로 멀티 에이전트 시스템 도입 효과를 조사하였다. 단일 에이전트 대비 작업 성공률은 평균 23.4% 향상되었으며, 병렬 패턴을 적용한 기업은 처리 시간이 평균 38% 단축되었다.

1. 조사 개요

조사 기간은 2026-07-01부터 2026-09-30까지이며, 응답 기업의 평균 연 매출은 1,250억 원이다. 설문과 심층 인터뷰를 병행하였다.

2. 패턴별 도입 현황

패턴도입 기업 비율만족도
Sequential Pipeline64%4.2 / 5
Coordinator / Dispatcher52%4.0 / 5
Parallel Fan-Out31%4.4 / 5
Generator & Critic27%4.1 / 5
Human-in-the-Loop45%4.5 / 5

3. 비용 분석

멀티 에이전트 도입 기업의 월평균 LLM API 비용은 $12,800로 단일 에이전트 대비 1.8배 높았다. 그러나 사람의 검토 시간 감소를 반영한 총비용은 평균 15% 절감되었다.

4. 주요 시사점

- 처음에는 Sequential Pipeline으로 시작하고 점진적으로 패턴을 추가한 기업의 성공률이 가장 높았다.
- 공유 상태(state) 키 이름 충돌로 인한 장애가 전체 장애의 18%를 차지했다.
- 결제·배포 등 고위험 작업에 승인 단계를 둔 기업은 사고 건수가 0건이었다.
