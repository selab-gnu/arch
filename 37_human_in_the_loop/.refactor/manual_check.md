# 직접 확인할 것 (자동 테스트로 못 보는 부분)

API 키가 설정된 PowerShell에서, 이 폴더로 이동한 뒤 실행하세요.

```
$env:PYTHONUTF8=1; .venv\Scripts\python adk_human_in_the_loop.py --demo --auto
```

1. 맨 위에 `🧠 사용 모델: ...`이 나오고 시나리오 5개가 차례로 실행되는가?
2. 시나리오 1(소액 정기 결제): `check_policy` → `process_payment`로 바로 송금되고, 멈추지 않는가?
3. 시나리오 2(고액 → 승인): `request_approval` 뒤 `⏸️ 실행이 멈췄습니다`가 나오고, `🤖 (--auto) 이선아 팀장: 승인`
   → `▶️ 승인 응답을 보내고, 멈춘 자리에서 재개합니다.` → 송금 완료가 나오는가?
4. 시나리오 2의 `📒 이번 요청으로 처리된 송금`이 **1건**인가? (재개 후 처음부터 다시 돌아 두 번 송금되면 안 됨)
5. 시나리오 3(신규 거래처 고액 → 거절): 거절 후 송금 0건인가?
6. 시나리오 5(잔액 부족): 멈추지 않고 차단 안내가 나오는가?
7. (선택) `--auto` 없이 `--demo`로 실행하면 승인 여부·승인자 이름·의견을 직접 입력받는가?

참고: AI 답변 문장은 매번 조금씩 다를 수 있습니다. 위의 흐름(자동 처리 / 멈춤 → 사람 응답 → 재개 / 차단)이 맞으면 됩니다.
